# BTAM Analyzer Reader

A GitHub Pages-ready demo tool for translating completed BTAM assessment forms and documentation into plain-language meaning, missing facts, immediate management actions, supportive measures, follow-up ownership, and proof-of-care documentation.

## Purpose

This tool helps school officials follow a simple flow:

Concern → Context → Behavior → Themes → Interpretation → Unknowns → Action → Support → Follow-up → Documentation

## Five-Year-Old Translation

The tool explains the concern in simple terms so a school official can quickly understand:

- what happened
- why it matters
- what is missing
- who should help
- what action happens next
- when the team checks back

## What This Tool Does

- Reads pasted BTAM assessment notes or summaries
- Detects common concern themes
- Converts complex assessment language into plain English
- Lists missing facts
- Produces immediate action steps
- Suggests support direction
- Creates a follow-up owner/date section
- Produces a proof-of-care statement

## What This Tool Does Not Do

This tool does not diagnose, predict violence, replace a BTAM team, replace law enforcement, replace mental-health judgment, or guarantee legal/regulatory compliance.

## Important Safety Notice

Use demo or training data only. Do not enter real student, employee, medical, disciplinary, threat, or personally identifiable information into a public GitHub Pages demo.
