# BTAM Assessment Interpretation Tool

Static GitHub Pages-ready demo for Palmer Venture LLC.

## Purpose
This tool helps end users translate BTAM-related concern information into plain-language meaning, management actions, supportive measures, follow-up, and documentation.

## What it is not
- Not a violence prediction tool
- Not a diagnostic tool
- Not legal advice
- Not medical/mental-health advice
- Not a replacement for a trained BTAM team
- Not a replacement for law enforcement, school administration, or clinical review

## GitHub Pages Deployment
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and this `README.md` to the repo root.
3. Go to Settings > Pages.
4. Source: Deploy from branch.
5. Branch: main.
6. Folder: root.
7. Save.

## Data Safety
Use demo or de-identified data only. Do not enter real student, employee, medical, disciplinary, threat, or personally identifiable case data into a public GitHub Pages site.

## Palmer Venture LLC Position
This is a workflow, documentation, and interpretation support tool. It supports structured thinking and follow-up. Final decisions must remain with trained, authorized humans using policy, law, and verified facts.
